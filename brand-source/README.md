# brand-source

Official brand files (source of truth). Do not edit; regenerate site assets with `pnpm brand`.

- `logo-transparent.webp`: master logo, transparent background (emblem + dark wordmark). Source for `pnpm brand`.
- `logo-white-bg.webp`: same logo on white.
- `banner-dark.webp`: official dark banner (white wordmark variant, tagline, contact row). Reference for dark-background usage.

`pnpm brand` extracts the emblem (ring + head) for the site, and builds favicons, PWA icons and the Open Graph image.
Still welcome if available: `MAIN_LOGO_BRAINSCOPE.pdf` / vector logo, `Visual_Identity_Brainscope.pdf`, `BrainscopeCenter_Signage.pdf`.
